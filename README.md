# CHRONO PILOT

コナミの『タイムパイロット』(1982) に着想を得た、全方向スクロールのシューティングゲームです。
自機は常に画面中央に固定され、世界のほうがスクロールします。各時代の護衛機を規定数撃墜すると
その時代の旗艦が現れ、これを撃破すると次の時代へタイムジャンプします。

依存パッケージなしのバニラ JavaScript (ES modules) + Canvas 2D で実装しています。

| タイトル | 1910 THE GREAT WAR SKIES | 1982 GUNSHIP CITY |
| --- | --- | --- |
| ![title](docs/screenshot-title.png) | ![1910](docs/screenshot-1910.png) | ![1982](docs/screenshot-1982.png) |

## モード

タイトルで決定するとモード選択に入ります。

| | 内容 |
| --- | --- |
| **ARCADE** | 素の機体で挑む、調整済みのスコアアタック。装備もドロップもなく、**バランスは固定**です |
| **SQUADRON** | 4機編隊で出撃する。僚機3機は現在 AI 操縦です |
| **SORTIE** | 空中でモジュールを拾い、旗艦からパーツを持ち帰る。周回して強い装備を掘るモード |

ARCADE は今後も現在のバランスのまま据え置きます。`tests/gear.test.js` が
「何も装備していない機体は素の機体と数値が完全に一致する」ことを検証しているので、
装備まわりをいじっても ARCADE の手触りには影響しません。

## 装備 (SORTIE)

**モジュール** — ザコが稀に、撃墜時にモジュール缶を落とします。触れるとその場で機体が
変化し、**そのランのあいだだけ**有効です。種類ごとに重ねられる上限があります。

全機体共通:

| | 効果 | 上限 |
| --- | --- | --- |
| RAPID | 連射 +12% | 4 |
| SPREAD | 砲門 +1 | 3 |
| PIERCE | 貫通 +1 | 3 |
| HEAVY | 威力 +1 | 3 |
| PLATE | 装甲 +1 | 4 |
| AGILE | 旋回 +0.4 | 4 |
| THRUST | 速度 +10 | 4 |
| REACH | 射程 +22% / 弾速 +6%。**段階的に伸びる** (5段で射程約3.6倍) | 5 |
| BLAST | 撃墜時に爆風 | 3 |
| POD | 随伴ポッド | 1 |
| MISSILE | **誘導ミサイル**。目標を撃墜すると次の目標へ切り替えます | 3 |
| FLARE | **フレア**。周囲に飛び込んだ敵弾を焼き落とします | 3 |

S.WIND 専用 (他機体には絶対にドロップしません):

| | 効果 | 上限 |
| --- | --- | --- |
| BIT | 随伴ビット +1 (**最大6機**) | 5 |
| LASER | **画面端まで届くレーザー**。射線上の護衛機を薙ぎ払い、旗艦を連続で削ります | 3 |
| SWARM | **画面内の敵全部へ同時に追尾ミサイル** | 2 |

**パーツ** — 旗艦を撃破するたびに1つ手に入り、保管庫 (`localStorage`) に残ります。
ENGINE / WING / GUN / ARMOR / AVIONICS の5スロットに装備でき、レアリティ
(COMMON / RARE / EPIC / LEGENDARY) が高いほど付与される能力の数と数値が上がります。
深い面で入手したものほど良いレアリティが出ます。装備は機体選択画面から `↓` (タッチは
LOADOUT) で開く画面で組みます。

実効ステータスは **素の機体 + パーツ + そのランで拾ったモジュール** を1箇所
(`resolveCraft`) で合成した結果です。すべての数値に上限があり、どれだけ積んでも
`tests/gear.test.js` の範囲を超えないことを検証しています。

保管庫は端末ごとです (`localStorage`)。スマホとPCで装備は共有されません。

## 編隊 (SQUADRON)

![squadron](docs/screenshot-squadron.png)

右上が編隊パネル (P3 EAGLE は撃墜されて復帰まで 1.2 秒)、左端の中抜きリングが画面外にいる僚機のマーカーです。

4機で1つの編隊を組んで飛びます。**現在は僚機3機を AI が操縦します。**
この席はそのまま、後からネットワーク越しの人間に置き換わる場所です。僚機は
`src/game/wingman.js` にあり、キーボードやタッチと**まったく同じインターフェース**
(`direction()` / `isHeld()` / `wasPressed()`) しか持ちません。ゲーム側は誰が操縦して
いるかを知らないので、通信を載せるときに `Game` 側を書き換えずに済みます。

- **カメラは自分の機体を追います。** 僚機は画面外に出ることがあるので、画面端に
  マーカーが出ます。**護衛機は時代色の小さな矢羽根、僚機は機体色の中抜きリング＋矢羽根、
  旗艦は大きな赤い矢印** の3種類で、一目で区別できます。
- **撃墜されても、パイロットは死にません。** 落とされた場所でパラシュートを開いて
  漂います。**僚機がパラシュートに接触して初めて復帰**し、そのとき残機は**1機も減りません**。
  誰も来なければ12秒でパイロットは失われ、そこで初めて1機を失って自動復帰します。
  残機を使い切った機体は `OUT` になり、**全機が OUT になって初めてゲームオーバー**です。
- パラシュートの間も**スティックで流される向きを変えられます** (弱く)。迎えに来た僚機に
  自分から半分寄れる、という意味です。敵はパラシュートを狙いません。
- 敵と旗艦は「一番近い機体」を狙います。誰か1人が囮になれる、ということです。
- 頭数に合わせて敵も増えます。撃墜ノルマ・同時出現数・湧き間隔は
  いずれも1機増えるごとに +50% されます (`squadScale`)。
- 画面右上の編隊パネルに、僚機ごとの装甲・`SOS` の残り秒数・`OUT` が出ます。

![rescue](docs/screenshot-rescue.png)

P2 は自機のすぐ横でパラシュート降下中 (残り7.4秒、リングが減っていきます)。右下の
P3 EAGLE が救助に向かっています。左端の白い丸は、画面外で残り2.6秒の P4 です。

**AI 僚機は救助を最優先します。** 戦闘中でも編隊のリードよりも優先して、いちばん近い
1機だけが向かいます (3機が同じパラシュートに群がっても誰も早く帰れないので)。

AI 僚機は編隊長 (自分) から 330px のリードで繋がれていて、狙う敵も編隊長の周囲
560px 以内に限っています。計測では **平均間隔 143px・最大 276px・同一画面内率 100%**
に収まりました。ただしこれは**リードの付いた AI の数字**です。人間が4人乗れば当然
散開しますし、そのためのマーカーです。

## 機体

タイトルで決定すると機体選択に入ります。左右キー（タッチはカード）で選び、ENTER / START で発進。

| | モチーフ | 装甲 | 予備機 | 性格 |
| --- | --- | --- | --- | --- |
| **VIPER** | F-2 | 5 | 2 | バランス。難易度カーブの基準機で、被弾後の無敵が一番長い |
| **DRAGON** | ドラケン | 4 | 2 | 機動性。最も小回りが利き当たり判定も最小だが、装甲・射程・火力は最低。撃たずに0.4秒以上ためると旋回がさらに上がる |
| **EAGLE** | F-15 | 7 | 2 | 火力。一発が重く旗艦に2倍ダメージ、撃墜時に爆風。連射が利かず、鈍重で当たり判定も大きい |
| **RAPTOR** | F-22 | 3 | 2 | ステルス。撃たなければ護衛機に捕捉されない。装甲は最薄、同時に持てる弾も3発だけ |
| **S.WIND** | 戦闘妖精雪風 | 6 | 2 | 隠し機体。3way＋貫通、随伴ポッド、自動ロックオン照準 |

**RAPTOR のステルス** — 射撃せずに1.7秒経つと護衛機から見えなくなります。護衛機は
こちらへ寄ってこず、撃ってもきません。撃った瞬間に位置が露見し、再び捕捉されます。
**旗艦はステルスを無視して常に追尾**するので、ボス戦は普通に戦うことになります。
状態は自機が半透明になることと、画面右下の `STEALTH` / `DETECTED` 表示で分かります。

機体のアートワークは `docs/` のデザインシート (`craft-sheet.png` と `craft-raptor.png`)
を元に生成しています。カード背景を外周からフラッドフィルで抜き、機首が +X を向くよう
回転し、データURIとして埋め込んだものが `src/render/craft-art.js` です。手で編集せず
`python3 tools/extract_craft_art.py` で作り直してください。カードごとに背景の明るさが
違うため、輝度しきい値は機体ごとに持たせています。画像の読み込みに失敗した場合はベクター描画にフォールバックするので、
絵が出ないことでゲームが遊べなくなることはありません。

S.WIND は 2084 の旗艦を撃破して1周すると解放されます。タイトル画面でコナミコマンド
（↑↑↓↓←→←→BA）、またはロックされたカードを3秒長押しでも開きます。解放状態は
`localStorage` に保存されるため端末ごとです。

機体定義は `src/game/craft.js` の1つの表にすべて入っています。`tests/craft.test.js` が
**通常機体3種はどれも他機体に全軸で勝ってはいけない**という不変条件を検査するので、
一強やハズレ機体は機械的に弾かれます。

## 遊びかた

### スマートフォン・タブレット

タッチ機器では画面上にコントロールが出ます。

- **左のスティック** — 画面左側のどこでも指を置いた場所がスティックの中心になります。そこから指を動かした方向へ旋回します。
- **FIRE ボタン** — 押しているあいだ射撃します。
- **AUTO** — 自動連射のオン / オフ。初期状態はオンなので、片手 (スティックだけ) でも遊べます。
- **BRAKE ボタン** — FIRE の内側。押しているあいだエアブレーキがかかります。
- **一時停止ボタン** — 右上。
- タイトル画面とゲームオーバー画面は画面タップで進みます。

画面の形に合わせて表示領域も変わります (縦持ちなら縦長、横持ちなら横長)。横持ちのほうが広く見渡せます。

### キーボード

| 操作 | キー |
| --- | --- |
| 旋回 (8方向) | 方向キー / `W` `A` `S` `D` |
| ショット | `SPACE` / `Z` / `J` |
| エアブレーキ | `SHIFT` / `C` |
| スタート・コンティニュー | `ENTER` (または `SPACE`) |
| ポーズ | `P` / `ESC` |
| ミュート切り替え | `M` |

- 自機は常に前進します。止まることはできません。入力した方向へ、旋回速度の範囲で機首を向けます。
- **エアブレーキ**を握ると減速して急旋回できます。旋回半径は `速度 ÷ 旋回速度` なので、
  減速そのものが旋回半径を縮めます (VIPER で 49px → 18px、約 62% 内側)。ただし
  **完全には止まれません**し、ゲージ制で約2秒しか保ちません。使い切ると**指を離すまで
  回復しません**。効きは機体ごとに違い、DRAGON が最も鋭く (73% 内側)、EAGLE が最も鈍い
  (42% 内側) ので、機体の性格がそのまま出ます。
- **被弾しても即座に失われません。** 機体ごとの装甲値（VIPERなら5）を1点ずつ削られ、
  0になって初めて1機失います。被弾直後は1.1秒無敵になるので、1回の接触で装甲が
  一気に溶けることはありません。残装甲は画面左下の `ARMOR` ゲージに出ます。
- 画面外の敵は画面端のマーカーで方向が分かります。**護衛機は小さく控えめな矢羽根、
  旗艦は大きな赤い矢印＋脈打つリング**で、一目で区別できます。
- 敵機も旋回速度に制限があるため、こちらを狙って突っ込み、行き過ぎて旋回して戻ってきます。
  この「すれ違いざまの撃ち合い」がゲームの中心です。
- 画面下の `FLAGSHIP` ゲージが満タンになると旗艦が出現します。旗艦が画面外にいるあいだは
  赤い矢印が方向を示します。
- 撃墜した敵からはパラシュート降下兵が出ることがあります。接触して救助するとボーナス
  (500 → 1000 → 2000 → 4000 → 8000 点) が入ります。ミスすると連鎖はリセットされます。
- 50,000 点ごとに自機が 1 機増えます。ハイスコアは `localStorage` に保存されます。

## 時代 (ステージ)

| | 時代 | 敵機 | 旗艦 | 背景 |
| --- | --- | --- | --- | --- |
| 1面 | 1910 | 複葉機 (レシプロ) | ZEPPELIN | 青空と積雲 |
| 2面 | 1940 | 単葉戦闘機 (レシプロ) | HEAVY BOMBER | 荒れた雲海 |
| 3面 | 1980 | ヘリコプター | ASSAULT GUNSHIP | 夜間の市街地 |
| 4面 | 2000 | 前進翼機 | STEALTH WING | 高層の巻雲 |
| 5面 | 2084 | UFO | MOTHERSHIP | 宇宙空間 |

2084 をクリアすると 1910 に戻り、敵の速度・旋回性能・同時出現数・射程が上がった
2 周目に入ります (1 周ごとに 28% ずつ強化)。

**1〜2面のザコは弾がほとんど飛びません。** 射程は 55〜65px、敵機 2 機ぶんほどで、
撃ってくるのも自機がその距離まで近づいたときだけです。事実上、ぶつかりに行かない限り
被弾しません。3面以降は 400px 以上の通常射程になります。旗艦だけは全時代で長射程
(380px〜) を持つので、1面でも撃ち合いになります。

難易度カーブは `src/game/levels.js` の表にすべて入っています。設計方針は 3 つです。

- **1910 はチュートリアル**。護衛機は自機の 4 分の 1 ほどの速度で、ほとんど撃ってこず、
  ツェッペリンは護衛を呼びません。初見でもここは抜けられるべき、という基準にしています。
  同時に出る機数は 4 機ありますが、少ないから簡単なのではなく**遅くて読めるから**簡単、
  という考え方です。
- **表の数値は面が進むほど必ず厳しくなる方向にしか動かない**。単調性は
  `tests/levels.test.js` で検証しているので、1 つの面だけ調整して curve が崩れると
  テストが落ちます。
- **年代はテーマの性質、難易度はスロット (何面目か) の性質**として分けています。
  面の入れ替えは、テーマ側のフィールド (label / subtitle / enemy / boss / scenery /
  sky / colors) だけをブロック間で移し、数値はその位置に残すことで行います。3面と4面の
  入れ替えもこの方法です。年代順とテーマの整合 (レシプロ機はジェット機より前、
  ステルス旗艦は 1990 年以降) もテストで固定しています。

## デバッグモード

**機体選択画面で、カードにもボタンにもかかっていない余白を10回連続でタップ**すると
デバッグモードが入ります (タップの間隔が1.2秒空くと数え直し)。もう一度同じ操作、または
パネルの `OFF` で解除。状態は `localStorage` に保存されます。

プレイ中は画面上部にパネルが出ます。無敵 / 当たり判定表示 / 次の面へ / 旗艦召喚 /
パーツ入手 / モジュール入手 / 全機体解放 / OFF。ボタンはタップでも、キーボードの
`1`〜`8` でも動きます。パネル下の1行に fps・状態・モード・面・撃墜数・エンティティ数・
装甲・実効ステータスが出ます。

## 実行

ES modules を使っているため、`file://` ではなく HTTP サーバー経由で開いてください。

```sh
npm start          # http://localhost:8080 で配信
# あるいは
npx http-server -p 8080
```

## テスト

```sh
npm test           # node --test (依存パッケージなし)
```

角度の正規化・最短回転・当たり判定・地形ハッシュなど、
描画に依存しない純粋なロジックを `tests/` で検証しています。

## 構成

```
index.html            画面と操作説明
src/main.js           起動処理とメインループの結線
src/core/loop.js      固定タイムステップのゲームループ
src/core/input.js     キーボード入力 (押下中 / このフレームで押された)
src/core/math.js      角度・乱数・当たり判定・決定性ハッシュ
src/core/audio.js     WebAudio による効果音 (音声ファイルなし)
src/render/sprites.js ベクター描画のスプライト (すべて +X 方向が機首)
src/game/game.js      状態遷移・スポーン・当たり判定の解決・描画順
src/game/levels.js    時代ごとの定義 (敵・旗艦・空・難易度)
src/game/background.js 無限にスクロールする視差背景
src/game/player.js    自機 (人・AI・通信のどれが操縦しても同じ)
src/game/wingman.js   AI 僚機 (入力と同じインターフェースだけを持つ)
src/game/parachutist.js 救助対象 (敵の脱出兵。味方の被撃墜は player.js 側)
src/game/enemy.js     護衛機の追尾 AI
src/game/boss.js      旗艦
src/game/effects.js   爆発・衝撃波・スコア表示
src/game/hud.js       スコア・残機・ゲージ・各種メッセージ
```

背景は状態を持ちません。各視差レイヤーをグリッドに区切り、セル座標を決定性ハッシュに
かけて中身を決めているため、世界は全方向に無限で、戻ってきても同じ景色になります。

## 今後の予定

- **オンライン協力プレイ** — SQUADRON の僚機席を、通信越しの人間に置き換えます。
  ホスト権威型 (ホストが `Game.update()` を回し、参加者は `{方向, 射撃}` だけを送る)
  で、20Hz のスナップショット + 参加者側の予測を予定しています。
- 攻撃パターンを持つ旗艦 (現状は追尾 + 3way 弾のみ)
- BGM と、時代ごとの効果音の作り分け
- Playwright によるヘッドレス動作テストの CI 組み込み
